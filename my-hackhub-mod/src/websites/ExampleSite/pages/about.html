This is the about page of . It demonstrates multi-page website navigation in HackHub mods.

Pages are linked using standard HTML anchor tags. The game browser automatically intercepts link clicks and navigates to the correct page.

Page Navigation Methods

  • HTML links: <a href="/about">About</a>
  • SDK: HackhubSDK.Browser.navigate(url)
  • SDK: HackhubSDK.Browser.push(url)

Available SDK APIs

  • HackhubSDK.UI — Toasts and notifications
  • HackhubSDK.Events — Game event system
  • HackhubSDK.Storage — Persistent data storage
  • HackhubSDK.Network — Network simulation
  • HackhubSDK.Mail — Email system
  • HackhubSDK.Bank — Banking system
  • HackhubSDK.Browser — Page navigation
